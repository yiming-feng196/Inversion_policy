# Legacy Studies

This directory contains earlier exploratory work on latent geometry, behavior-region localization, and temporal region tracking. These scripts remain available for historical context but are outside the active Prior Flow pipeline.

- `latent_geometry/`: offline analyses of inversion-latent structure and local geometry.
- `behavior_region_tracking/`: earlier behavior-region localization and temporal-reuse experiments.

For the active method, use [`../prior_policy/`](../prior_policy/README.md).
